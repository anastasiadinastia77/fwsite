# FW LABEL NETWORK

Перед изменениями интерфейса прочитайте [DESIGN.md](DESIGN.md): там зафиксированы согласованные правила дизайна и ограничения демоверсии. Новые указания пользователя имеют приоритет.

Используйте существующий checkout. Проверки и команды запуска описаны в README.md. Последний референс заказчика: тёмная музыкальная афиша, чёрный фон, светлый текст, оранжевые акценты, крупный одиночный портрет и плотные прописные заголовки Roboto Condensed. Без курсива, коллажей и винила. Предыдущая светлая версия сохранена в Git (0b08a80). Источники сведений и фотографий указаны в MEDIA_SOURCES.md. Участие артистов не подтверждено; демо-заказ работает только с вымышленным экспертом. Основной текст должен оставаться крупным и читаемым. Не подключайте реальные платежи, Telegram API, отправку файлов, аналитику или платные сервисы без отдельной задачи.
