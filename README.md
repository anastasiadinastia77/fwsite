# FW LABEL NETWORK — интерактивный прототип

Минималистичный русскоязычный сайт музыкальной платформы: проблема музыканта и конкретные результаты → выбор жанра → учебный пример рекомендаций → потенциальные эксперты → отдельный демо-заказ. Пример явно обозначен как вымышленный, без записи голоса или отзыва реального артиста.

**M.O.S., Maxxim, Gydra, Alexander Popov и DEFLEE пока не подтвердили участие.** Их карточки не принимают заказы. Тестовый заказ оформляется у вымышленного эксперта; реальные артисты не получают трек или сообщения. Платежи, Telegram API, отправка файлов, аналитика и UTM отключены.

## Открыть сайт

Публичная тестовая версия: https://anastasiadinastia77.github.io/fwsite/

После обновлений дождитесь успешного процесса **Publish FW LABEL NETWORK** во вкладке Actions. Если браузер показывает старую версию, обновите страницу с Ctrl+Shift+R или добавьте к адресу `?v=номер-коммита`.

## Запустить в рабочей среде

Нужны Node.js 22.12+ (проверено на 24) и npm. В терминале:

```bash
cd /workspace/fwsite
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

Первая команда переходит в проект, вторая устанавливает зависимости по зафиксированному списку, третья запускает сайт. Если зависимости уже установлены, достаточно последней команды. Ctrl+C останавливает сервер.

В редакторе с панелью «Порты»/«Предпросмотр» откройте порт 5173. Сам интерфейс настройки среды может не поддерживать предпросмотр. Публикация облачного окружения не равна публикации сайта.

## Что попробовать

1. Выберите жанр. Откройте профиль потенциального эксперта, ознакомьтесь с описанием и ссылкой на страницу артиста.
2. Нажмите «Попробовать с демо-экспертом» или «Попробовать демо» под каталогом. В заказе появится вымышленный профиль нужного жанра, а не имя артиста.
3. Введите вымышленные данные и нажмите «Симулировать оплату».
4. После демо-оплаты выберите тестовый MP3/WAV. Считываются только имя и размер; файл не отправляется и не сохраняется.
5. Симулируйте передачу и голосовой разбор. Плеер — визуальный макет без записи.
6. Задайте один или два вопроса. Повторный раунд в этом заказе недоступен. 72 часа показаны подписью, без таймера.
7. Покажите демо-ответ и ознакомьтесь с премиальными возможностями.

Данные живут в памяти страницы. Закрытие заказа или обновление страницы сбрасывает демо.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

`typecheck` проверяет типы, `lint` — правила кода, `test` — этапы заказа, жанры и отделение реальных кандидатов от демо-эксперта. `build` собирает сайт в `dist`. `test:e2e` проходит заказ в браузере, проверяет мобильную навигацию и отсутствие внешних запросов/POST при сценарии.

Браузерные проверки настроены на Chromium в `/usr/bin/chromium` в этой среде. На другом компьютере настройте `executablePath` в `playwright.config.ts` или используйте браузер Playwright. Снимки экранов создаются в `artifacts/` и не включаются в Git.

## Файлы

- `src/main.tsx` — лендинг, каталог, профиль и демо-заказ.
- `src/data.ts` — реальные кандидаты отдельно от вымышленных демо-экспертов.
- `src/style.css` — минималистичное оформление и адаптация под телефон.
- `public/experts/` — локальные изображения.
- `MEDIA_SOURCES.md` — источники сведений и изображений, оставшиеся ограничения.
- `DESIGN.md` — правила дизайна для следующих изменений.
- `src/data.test.ts`, `e2e/demo.spec.ts` — проверки.

Портреты M.O.S. и Gydra предоставлены заказчиком через GitHub и подключены к карточкам. Фото Maxxim и DEFLEE, а также изображение Interplay Radioshow для Alexander Popov найдены в профилях SoundCloud. Все пять карточек показывают изображения. Источники и история замены указаны в MEDIA_SOURCES.md. Рейтинги лейблов не опубликованы без датированного источника.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет, собирает и публикует изменения из `main`. В Settings → Pages → Source выбран **GitHub Actions**. Сборка для Pages использует `npm run build -- --base=/fwsite/`. Это позволяет правильно загружать скрипты, оформление и фотографии из подпапки `/fwsite/`.

React + TypeScript + Vite, без сервера. Отдельных маршрутов пока нет: разделы открываются по якорям, профиль и заказ — в окнах. Все фотографии и шрифты загружаются с самого сайта. Внешние сервисы и ключи для работы прототипа не требуются.
